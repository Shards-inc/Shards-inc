## Rollback

Use Cloudflare Workers version deployments to restore the previous known-working release (21-source quick search remained available before deep UI). Do not roll back the D1 schema as this may invalidate concurrent jobs. Always check current deployed version and active scan state before changing traffic.

## Privacy obligations

- Keep raw usernames out of application logs and durable scan history.
- Treat 'claimed' site records as heuristic leads until corroborated.
- Never misrepresent upstream 403/429/CAPTCHA as proof of an absent account.
- Explain to users that public sites receive their username during the search.
- Delete expired temporary job and permit records and revise use of deterministic username hashes before a paid launch.

## Temporary result preservation (v0.3)

The scanner publishes a terminal snapshot to the Cloudflare `/api/identity/deep/complete` endpoint with the existing per-job status secret. Cloudflare verifies the session is unexpired, validates the payload, and persists it in D1 `identity_deep_results` using `INSERT OR IGNORE` to make callback retries idempotent. The status endpoint checks the completed snapshot only after verifying the session cookie. An hourly scheduled handler removes expired records. The snapshot is accessible for at most 30 minutes after job creation; physical deletion may lag by up to an hour. This is not a durable in-flight queue. Do not advertise disaster recovery until a real Render-restart test passes.

## Privacy incident fix: provider error logging

During 11 November 2026 verification, Render logs were found containing the queried username in large upstream error messages generated by Maigret. They did not originate from our user-facing API responses. New code disables detailed site-library loggers and strips exception tracebacks from scan errors while keeping generic operational warnings. This does not erase historical logs already retained by Render; historic log redaction/deletion must be assessed through the provider and retention policy. Verify a fresh live scan emits zero raw username log entries before advertising log-minimisation compliance.
